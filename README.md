
# FinCopilot 🧠

ReAct-агент для фин.аналитики на локальной Qwen2.5 + Ollama.

## Запуск
1. ollama pull qwen2.5:7b-instruct-q5_K_M
2. pip install -r requirements.txt
3. streamlit run app.py

## Использование
- Загрузите Excel/PDF в inputs/
- Выберите шаблон или напишите запрос
- Получите Excel: полный отчёт или отдельный лист/диаграмму
